

## 🧑‍💼 Employee Dashboard

A modern, responsive employee management dashboard built with **HTML**, **CSS (Tailwind)**, and **JavaScript**. This app interacts with a RESTful API to perform full **CRUD operations** (Create, Read, Update, Delete) on employee records.

<br/>

### 🔗 **Live Demo**

[➡️ Click here to try it live](https://nikmahla.github.io/Employee-Dashboard/)

---

### ✨ Features

* ✅ Display paginated employee list with responsive design
* 🖼️ Auto-load profile images (with fallback handling)
* ➕ Add new employee via modal form
* 📝 Edit existing employee info
* 🗑️ Delete employee with confirmation modal
* 🔍 Toggle “more info” row for extra employee details
* 📱 Fully responsive using **Tailwind CSS**
* 📡 Connected to **MockAPI** for real-time REST data handling

---

### ⚙️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript (ES6+)**
* **MockAPI** (for testing REST endpoints)
* **GitHub Pages** (for deployment)
